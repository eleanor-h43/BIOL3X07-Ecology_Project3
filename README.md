## Overview

This project investigates how prescribed burning (or hazard-reduction burning) affects bird vocal activity in the Greater Blue Mountains. Recorders were deployed across burned and unburned sites before and after a planned burn, and recordings will be processed with BirdNETto detect how species activity changes over time.
